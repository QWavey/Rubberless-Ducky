Get started

Download the firmware image, put the device into DFU mode, flash. Reference and an in-browser flasher below.

Alpha. Read this first. Do not flash this firmware onto a device that already works. Not every DuckyScript opcode is implemented, and the SD-card path has known rough edges. It exists to bring back devices that are already bricked, or that you want to run open firmware on. If you flash a healthy device you are trading working stock firmware for known-incomplete work, and the stock firmware cannot be restored from here.

02Flash it (Windows)

01

Enter DFU (bootloader) mode

Unplug the device. Hold the small button on the board (labeled BOOT, HWB, or similar) and, while holding it, plug the device back in. Release the button after about a second. The device now waits silently for a firmware upload. It will not appear as a keyboard.

02

Install WinUSB with Zadig (first time only per PC)

Open Zadig. From the menu, Options → List All Devices. In the dropdown pick AT32UC3B DFU. On the right pick WinUSB. Click Install Driver. Wait for it to finish. This is a one-time step.

03

Put firmware.hex and dfu-programmer.exe in the same folder

Both are one-click downloads above.

04

Open a Command Prompt as Administrator in that folder and run

dfu-programmer at32uc3b1 erase --force
dfu-programmer at32uc3b1 flash firmware.hex
dfu-programmer at32uc3b1 launch

The device disconnects from DFU mode, re-enumerates as a HID keyboard, and the status LED goes solid when it is ready.

03Flash it (in-browser, experimental)

Everything below runs on this page over WebUSB. It still needs Zadig on Windows (step 2 above), because Chrome cannot talk to a device that Windows has attached a different driver to. On Linux, a udev rule for VID 03EB is enough.

Known limit The Atmel DFU bootloader on AT32UC3B does not advertise WebUSB descriptors, so Chrome will only offer the device in its picker if no other driver has claimed it. If the device does not show up, use the manual path above.

04Build it yourself

Clone the repo. Add tools/AVR Toolchain/bin/ to PATH. Run:

make all

Output lands at build/firmware.hex. Copy it over firmware.hex at the repo root to bundle a fresh build with this flasher page.

05Reference

USB identity

  • VID 0x03EB (Atmel), PID 0x2402 in application mode
  • PID 0x2FF6 in DFU mode
  • HID keyboard, 64-byte reports (0x01 OUT, 0x02 IN), 1 ms polling

Memory map

0x80000000..0x80001FFF   8 KB   Factory DFU bootloader (preserved)
0x80002000..0x8003FFFF   248 KB App firmware (this)
0x00000000..0x00007FFF   32 KB  SRAM (stack, data, BSS)
0xFFFE0000..0xFFFEFFFF   64 KB  USBB peripheral FIFOs

Rubberless-Ducky Flasher

Open AT32UC3B1 firmware for reviving bricked Hak5 USB Rubber Ducky hardware. This page hands you the firmware and walks you through flashing it.

Alpha. Read this before you flash. Do not flash this firmware onto a device that already works. It is unfinished, not every DuckyScript opcode is implemented, and the SD-card path has known rough edges. It exists to bring back devices that are already bricked or that you specifically want to run open firmware on. If you flash a healthy device, you are trading working stock firmware for known-incomplete work. The stock firmware cannot be restored from here.

Flash it (easy path, Windows)

  1. Put the device into DFU (bootloader) mode.
    Unplug the device. Hold the small button on the board (labeled BOOT, HWB, or similar), and while holding it, plug the device back into USB. Release the button after one second. The device is now silent to the operating system, waiting for a firmware upload. It will not show up as a keyboard.
  2. Install the WinUSB driver with Zadig (first time only).
    Open Zadig. From the menu, choose Options → List All Devices. In the dropdown, pick the entry that looks like AT32UC3B DFU. On the right, select WinUSB. Click Install Driver. Wait for it to finish. You only ever do this once per PC.
  3. Download the firmware and dfu-programmer.
    Use the buttons above. Put firmware.hex and dfu-programmer.exe in the same folder.
  4. Open a Command Prompt as Administrator in that folder and run these three commands in order: 
    dfu-programmer at32uc3b1 erase --force
dfu-programmer at32uc3b1 flash firmware.hex
dfu-programmer at32uc3b1 launch
    The device disconnects from DFU mode, re-enumerates as a HID keyboard, and the status LED goes solid when it is ready.

Flash it (experimental, no installers)

WebUSB flashing runs entirely in this page, in Chrome or Edge. It still needs Zadig on Windows (step 2 above), because Chrome cannot talk to a device that Windows has attached a different driver to. On Linux, a udev rule for VID 03EB is enough.

Known limitations. The Atmel DFU bootloader on AT32UC3B does not advertise WebUSB descriptors, so Chrome will only offer the device in the picker if no other driver has claimed it. If the device does not appear, use the manual path above.
Ready.

Build it yourself

Clone the repo. Add tools/AVR Toolchain/bin/ to PATH. Run make all. The output lands at build/firmware.hex.

Rubberless-Ducky is a clean-room reimplementation.

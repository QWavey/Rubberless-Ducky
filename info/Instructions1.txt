HOW PAYLOADSTUDIO WORKS NORMALLY:

The compiler translates human-readable DuckyScript commands (like ENTER, STRING Hello, CTRL ALT t) into binary USB HID keycodes that the USB Rubber Ducky (or other Hak5 device) can understand and inject.

Lookup Table (IDE_CONFIG['ducky_lang']): The core of this translation is a large JavaScript object (defaultUSKbdLayout in the code) that maps a string (e.g., 'a', 'ENTER', 'CTRL') to a keycode in the format "modifier, reserved, keycode".

Example: 'a': '00,00,04'

Example: 'ENTER': '00,00,28'

Example: 'CTRL': '01,00,00'

The lookupAndAppend Function: This is the primary function called by commands like STRING and single modifiers. It looks up the string in the language table.

getBytesForKey(k, fullwidth): This helper function is called by lookupAndAppend. It looks up k in the IDE_CONFIG['ducky_lang'] map, parses the string (e.g., "00,00,04"), and returns a byte array.

For a standard key like 'a', it returns ['04'] (the keycode).

For a key with a modifier (if the language table entry has a non-zero modifier), it returns [keycode, modifier].

For a modifier key alone (like 'CTRL'), it returns ['01'].

appendHexStringArray(hexStringArray): The final byte(s) from getBytesForKey are passed to this function, which pushes them into the global output buffer array oBB. This buffer is eventually joined and saved as inject.bin.

Delay Insertion: After processing a line (and its resulting keycodes), the doDelayCheck() function is called. If DEFAULT_DELAY or DEFAULTDELAY was set and no explicit DELAY was on the current line, it builds and appends the delay bytes (00, XX).

How a Modifier+Key Combo Works (e.g., CTRL ALT t)
The compiler is smart enough to handle combinations like CTRL ALT t by OR-ing the modifier bits together.

Lookup individual parts:

CTRL -> 01 (Modifier bit)

ALT -> 04 (Modifier bit)

t -> 17 (Keycode), 00 (no modifier on its own)

Combine Modifiers: The modifier bits are OR-ed together: 01 | 04 = 05. (Byte 05 means CTRL + ALT).

Final Injection: The injected payload for CTRL ALT t would be the combined modifier byte 05 and the keycode 17.

Result: ['17', '05']

(Note: For commands like CTRL-ALT in the language table, it's already defined, so lookupAndAppend would handle it in one go.)

How a STRING Command is Compiled (e.g., STRING Hello)
The handleString function iterates through each character of the string.

'H' -> Looks up 'H' in the table: '02,00,04'. Injects ['04', '02'] (keycode '04' + shift modifier '02').

'e' -> Looks up 'e': '00,00,08'. Injects ['08', '00'].

'l' -> Injects ['0f', '00'].

'l' -> Injects ['0f', '00'].

'o' -> Injects ['12', '00'].

The final output for STRING Hello would be a sequence of these byte pairs: 04 02 08 00 0f 00 0f 00 12 00.
